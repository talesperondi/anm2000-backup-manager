ANM2000 Backup Manager 1.0.0
============================

O que este programa faz
-----------------------
Automatiza duas rotinas do cliente ANM2000 (Fiberhome):

  * Save Config To Flash em todas as OLTs da topologia;
  * Export Configuration do ANM2000 para uma pasta datada.

Cada operacao e confirmada de verdade: o flash so e considerado concluido
quando o cliente responde "Command Succeed" e o export so e aceito quando
os arquivos aparecem no disco.

Requisitos
----------
  * Windows 10/11 (64 bits);
  * cliente ANM2000 instalado, aberto e autenticado;
  * sessao do Windows desbloqueada nas execucoes agendadas.

O programa NAO armazena senhas. Ele usa o cliente ANM2000 que ja esta
aberto e autenticado.

Primeiros passos
----------------
1. Abra o ANM2000 e faca login.
2. Abra o "ANM2000 Backup Manager".
3. Confira a raiz dos backups (padrao C:\ANM2000) em Configuracoes.
4. Crie um agendamento em "Agendamentos".
5. Deixe "Iniciar com o Windows" marcado para o programa subir sozinho
   depois de reiniciar o PC.

Apos reiniciar o Windows, entre na sua conta e autentique o ANM2000.
Se o horario do backup tiver passado, o programa executa a ocorrencia
perdida automaticamente (catch-up).

Dados e backups
---------------
  * Configuracoes, historico e logs:
      %LOCALAPPDATA%\ANM2000BackupManager
  * Backups:
      C:\ANM2000\OLT_FLASH\AAAA-MM-DD
      C:\ANM2000\ANM2000_EXPORT\ANM2000_Backup_DD-MM-AAAA

Os backups antigos nunca sao apagados automaticamente. A desinstalacao
nao remove seus backups nem o historico.

Aviso
-----
Este e um projeto independente, sem vinculo oficial com a Fiberhome.
A automacao usa a interface do cliente; atualizacoes do ANM2000 podem
exigir ajustes. Teste em um ambiente controlado antes de usar em producao.
